# 物理信息代理 × 振动采收参数优化 —— 研究设计文档

> 状态:设计阶段(2026-06)。本文档把"陌生树 → 最优采收参数"的目标落成可执行的研究/工程方案,
> 并明确哪些已在现有代码里、哪些是待补缺口。

## 1. 目标(North Star)

面对一棵**陌生果树**,在**不做复杂前期试验**的前提下(仅几何 + 树种),
**快速(田间实时)**计算出振动采收的**最优作业参数**:

- 激励**频率** f [Hz]
- 激励**幅度/力** A [N]
- 激励**位置**(施加在哪根枝/哪个节点)
- 作业**时长** T [s]

约束:运行在 GPU/边缘设备上毫秒级推理,材料只能用树种先验(零样本)。

## 2. 为什么是物理信息方法(而非纯 FEM / 纯黑箱 ML)

- **vs 纯 FEM**:准但慢(每次前向数秒),且需逐树标定材料 → 违背"免试验 + 实时"。
- **vs 纯黑箱 ML**:仅 ~5 棵树,数据极稀,无法泛化到陌生树。
- **物理信息 + 图结构**:FEM 残差/结构是强归纳偏置,数据高效、可外推到没见过的几何/拓扑,
  这正是"陌生树零样本"需求的技术核心。

## 3. 关键现实约束:零样本 ⇒ 做"鲁棒优化",不做"点预测"

绿木的 E / 密度 / 阻尼个体差异大且无法从照片测得。仅凭几何 + 树种**无法精确预测某棵树的共振频率**。
因此交付目标重定义为:

> 把树种材料先验当作**带不确定性的输入**,传播到响应分布,优化**对材料变异稳健**的作业参数
> (最大化期望脱落 / 最坏情况脱落),而非追求单点最优。

这把零样本的劣势转成方法贡献。`recommend` 命令已有 `detachment_coverage_median - 0.05*ci_span`
的雏形,可沿此方向扩展为完整 UQ。

## 4. 三级流水线架构

| 级 | 职责 | 输入 → 输出 | 现有件 |
|---|---|---|---|
| ① 表征 | 廉价观测 → 树模型 | 几何(拓扑/直径/长度,来自照片/LiDAR)+ 树种先验 → 模型参数 | `examples/trees/*.json` 示例、`workspace/tree_models/` 本地导入 |
| ② 快速预测 | 树 + 作业参数 → 响应/脱落 | (图, f, A, 位置) → 响应 / 脱落率 | `orchard_pinn/data/generator.py`(LHS+FEM→npz)、FEM 真值 |
| ③ 优化 | 搜最优作业参数 | 响应模型 → argmax 鲁棒目标 | `harvest/optimization.py`、`recommendation/pareto.py` |

**② 的代理模型**:GNN over 枝条图(节点=枝段,边=连接/关节;节点/边特征=直径/长度/材料先验/果实质量),
损失含 FEM 残差;材料作为不确定输入。GNN 天然处理变拓扑 → 泛化到陌生树。

**内嵌方法贡献**:在边上嵌入**可学习的非线性闭合**(关节力矩-转角 / 幅值相关阻尼),
离线用多树实测锤击 FRF 训练,保证代理在采收大幅非线性区有效。对接已有的 Duffing /
二次阻尼验证与谐波平衡 / describing-function 机制。

## 5. 采收目标函数(本文档要拍板的核心)

### 5.1 已有的脱落判据(`harvest/detachment.py`)
单频惯性力判据:`F_inertia = m·ω²·|H(ω)| ≥ F_detach = k·d_detach`。
已实现频率维优化(top-N 脱落率)。

### 5.2 待补缺口(相对 4 参数目标)
| 维度 | 现状 | 缺口 / 待做 |
|---|---|---|
| 频率 f | ✅ 已扫频优化 | 受零样本不确定性影响最大 → 鲁棒化 |
| 位置 | ⚠️ 取全局最大响应,未区分每个果实所在节点 | 让每个果实用**其所在节点**的响应;返回最优激励位置 |
| 幅度 A | ⚠️ FRF 默认单位力,未按真实力幅缩放 | 线性区按 A 缩放响应;非线性区由闭合给幅值相关响应 |
| 时长 T | ❌ 未建模 | 需**脱落累积 / 疲劳模型**(瞬态),非稳态 FRF 量;v1 可简化/搁置 |
| 损伤 | ❌ FRF 无应力输出 | 新增枝条应力/弯矩代理作为约束 |
| 能耗 | ❌ 无 | 由 A、f、T 构造能耗代理 |

### 5.3 拟定目标函数(待与团队确认权衡)
```
maximize_robust   E_θ[ DetachFraction(f, A, pos, T; tree, θ) ]
subject to        max_θ BranchStress(f, A, pos; tree, θ) ≤ σ_allow      (损伤硬约束)
                  Energy(f, A, T) ≤ E_budget                            (能耗约束)
其中 θ ~ 树种材料先验分布(零样本不确定性)
```
- **默认建议**:脱落率为主目标,损伤为**硬约束**,能耗/时长为次目标或 Pareto 维度。
- 待定:损伤是硬约束还是软惩罚?能耗是否纳入(取决于执行器)?→ 见 §8 开放项。

## 6. 数据与离线训练

1. 多树锤击 FRF → 学非线性闭合 + 标定各树材料(线性参数辨识作副产品)。
2. 用 `generator.py` 扩样本(增加阻尼 α/β、激励幅度维度)生成 (几何, 参数) → 响应 数据。
3. 训练物理信息 GNN 代理;材料作为不确定输入;闭合嵌于边。

## 7. 验证方案(决定成败)

**留一棵树(leave-one-tree-out)**:4 棵训练,对第 5 棵**只给几何 + 树种**预测鲁棒最优参数;
用该树实测验证,重点报告:在该树**真实(未知)材料**下,推荐参数是否仍有效。

辅助实验:
- 消融阶梯:线性 < 参数化 Duffing < NN 闭合,精度逐级提升。
- 鲁棒 vs 标称优化对比(零样本下鲁棒解的优势)。
- 推理速度 benchmark(证明实时可行)。

## 8. 风险与开放项

- **材料先验不准 → 系统性偏差**:靠鲁棒优化 + UQ 兜底,勿靠点预测。
- **闭合可迁移性**:闭合从训练树学,零样本假设迁得动 → 必须用留一树验证。
- **仅 5 棵树**:对"泛化"是硬伤,论文须正面讨论,并尽量多采树。
- **开放项 ①**:损伤约束是硬还是软?σ_allow 取值依据?
- **开放项 ②**:能耗/执行器模型是否纳入?
- **开放项 ③**:时长维度需脱落累积模型——v1 是否搁置?

## 9. 领域新颖性(文献空白)

农业 PINN 文献几乎全是作物产量/生物量 ODE 模型(AgriPINN 等);
**果树采收的机械振动动力学尚无人用物理信息 ML 处理**。
"梁/结构 PINN 方法 × 果树采收应用"是新颖性落点。

## 10. 分阶段计划与代码落点

1. **C(已完成核心)**:时长累积模型 + 两级损伤目标 `harvest/objective.py`;单元级应力恢复
   `harvest/stress_recovery.py`(`f=k·u` 端弯矩 → σ,悬臂梁解析解验证)。
   - **待接线 C-1**:全网络应力聚合——需(a)求解器保留全复解向量,
     (b)装配器把每单元截面外缘 `c`/完整 `BeamElementProperties` 透传进 `BranchElementState`。
     接好后即可用真应力替换 `objective` 里的 `branch_peak_stress` / `clamp_stress` 代理。
   - **待做 C-2**:位置维——每果实用其所在节点响应(而非全局最大),返回最优激励位置。
2. **数据**:扩 `orchard_pinn/data/generator.py` 采样维度。
3. **代理**:实现 `orchard_pinn/surrogate/`(物理信息 GNN + UQ)。
4. **闭合**:`orchard_pinn/inverse/` 离线学非线性闭合。
5. **优化**:鲁棒 4 参数优化,扩展 `harvest/optimization.py` + `recommendation/pareto.py`。
