Orchard FEM conda environment commands
======================================

Principle
---------
1. Keep the high-fidelity solver work (PETSc/SLEPc/FEniCSx) + tests in one main env.
2. Keep PyTorch surrogate / inverse work separable from the solver stack to reduce dependency conflicts.


Environment A: FEniCSx / PETSc / SLEPc backend (primary)
-------------------------------------------------------
Important:
- Recommended target platform: Ubuntu, WSL2 Ubuntu, or native Linux
- This is the main environment: solver, verification, AND the Python integration
  tests / plotting / repo scripts / actuator GUI + rig tooling. It carries
  pytest, ruff, numpy, scipy, matplotlib, pyserial, tkinter alongside FEniCSx.

Purpose:
- orchard_fem modal / frequency / time solver
- PETSc / SLEPc eigen and linear solve backend
- DOLFINx integration
- run Python integration tests and the actuator console / DS5L1 rig tooling

Command:
conda env create -f config/fenicsx_pinn_environment.yml

Activation:
conda activate orchard-fenicsx

Optional:
- If you also want PyTorch here and the solver resolves cleanly:
  conda install -n orchard-fenicsx -c pytorch -c conda-forge pytorch


Environment B: PyTorch inverse / surrogate
------------------------------------------
Purpose:
- orchard_pinn inverse MVP
- local nonlinear surrogate
- response surrogate and dataset work

Command:
conda create -n orchard-ml -c pytorch -c conda-forge python=3.11 pytorch numpy scipy pandas matplotlib h5py pyyaml pytest pytest-cov jupyterlab

Activation:
conda activate orchard-ml


Minimal recommended rollout order
---------------------------------
1. Create orchard-fenicsx inside Ubuntu / WSL2 Ubuntu (main env)
2. Create orchard-ml when you start PINN / surrogate work


Post-install checks
-------------------
After activating any environment, run:
python -m orchard_fem doctor
python -m orchard_fem --help
